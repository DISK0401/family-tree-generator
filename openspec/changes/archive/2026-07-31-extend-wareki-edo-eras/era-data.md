# 元号データ対照表(作業メモ)

extend-wareki-edo-eras のタスク1.1の成果物。`src/domain/wareki.ts` の `ERA_TABLE` に収録した
大化〜慶応の234元号の対照表。

## 方針

- **典拠**: Wikipedia「[元号一覧 (日本)](https://ja.wikipedia.org/wiki/元号一覧_(日本))」(2026-07-31取得)。
  主要な改元日(大化・文亀・天保・慶応・明治ほか)は各元号の個別記事および検索で相互確認した。
  改元日の西暦換算は1582年10月4日以前がユリウス暦、1582年10月15日以降がグレゴリオ暦。
- **テーブル格納値(nominal方式)**: 明治より前の行の `start`/`end` は、旧暦(太陰太陽暦)の
  改元年月日を「慣用の西暦対応年 + 旧暦の月日」の名目上の日付として格納する
  (例: 天保の開始 = 文政13年12月10日改元 → `{ year: 1830, month: 12, day: 10 }`)。
  和暦入力の年月日をそのまま西暦フィールドへ写す既存の変換方式(天文学的換算をしない)と
  整合し、`元年`に対応する西暦年(天保元年=1830)・改元月日での境界判定・往復変換が
  既存ロジックのまま正しく機能する。閏月改元(延長=延喜23年閏4月11日)は同じ番号の月に畳む。
- **終端の導出**: 各元号の `end` は次の元号の開始日の名目上の前日(旧暦の月は最大30日として
  計算)。例外は次の3件。
  - 白雉: 白雉5年12月30日(ユリウス暦655-02-11)で中断 → `end = 654-12-30`。以後、
    斉明天皇重祚により朱鳥まで元号なし(空位)。
  - 朱鳥: 朱鳥元年閏12月30日(ユリウス暦687-02-17)で中断 → `end = 686-12-30`。以後、
    大宝まで元号なし(空位)。
  - 慶応: 名目上の終端を明治開始日(グレゴリオ暦1868-10-23)の前日 `1868-10-22` に置く。
    改元日ベース(慶応4年9月8日=明治改元)より広く取ることで、旧文書に残る
    「慶応4年9〜10月」表記も受理する。
- **南北朝期(1331〜1394年)**: 元徳→元弘(元徳3年8月9日改元)→建武→北朝系列
  (暦応・康永・貞和・観応・文和・延文・康安・貞治・応安・永和・康暦・永徳・至徳・嘉慶・
  康応・明徳)→応永 の単一系列を収録。元弘と並立した北朝の正慶(1332〜1333)、および
  南朝元号(延元・興国・正平・建徳・文中・天授・弘和・元中)は非収録(入力すると
  「元号「◯◯」には対応していません」)。
- **大化の改元日**: 改元詔の日(大化元年6月19日=ユリウス暦645年7月17日)を採用。
