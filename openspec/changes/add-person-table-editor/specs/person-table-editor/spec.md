# person-table-editor

## Purpose

登録されている全人物を1行1人の表として閲覧し、Excel ライクな編集モードでセル編集・矩形コピー&ペースト・行追加による人物追加を行えるサポート機能。1人ずつのフォーム入力(図+右側パネル)を置き換えるものではなく、数十人規模の書き写し入力と属性の抜け漏れ走査(校正)を補完する第二の入力面として定義する。

表での編集は既存のドメインコマンドを通る通常の編集であり、検証・自動保存・undo/redo・マルチタブ保護のふるまいは図・パネルでの編集と区別されない。

## ADDED Requirements

### Requirement: 表形式ビューと図の切り替え

エディタは、登録されている全人物を1行1人で表示する表形式ビューを提供しなければならない(MUST)。利用者は図(キャンバス)と表を明示的な操作で切り替えられなければならない(MUST)。切り替え自体は家系図データを一切変更してはならない(MUST NOT)。

人物編集フォーム(右側パネル)に未確定の変更がある状態で表へ切り替えようとした場合、既存の人物切り替えと同じ離脱確認(保存して移動/破棄して移動/編集を続ける)を経なければならない(MUST)。

#### Scenario: 図から表へ切り替える
- **GIVEN** 人物が登録された家系図をエディタで開いている
- **WHEN** 表示を表形式ビューへ切り替える
- **THEN** 登録されている全人物が1行1人の表として表示され、家系図データは変化しない

#### Scenario: 未確定の変更がある状態での切り替え
- **GIVEN** 右側パネルの人物編集フォームに未確定の変更がある
- **WHEN** 表形式ビューへ切り替えようとする
- **THEN** 離脱確認が表示され、「編集を続ける」を選ぶと切り替えは行われない

### Requirement: 列構成

表の列は、人物編集フォーム(右側パネル)で参照・変更できる人物属性を含まなければならない(MUST): 姓・名・姓(ふりがな)・名(ふりがな)・性別・生年月日・出生地・没年月日・没地・メモ。

加えて、閲覧用の「配偶者」列(配偶者の氏名の一覧)を表示しなければならない(MUST)。配偶者列は読み取り専用であり、表から編集を開始できてはならない(MUST NOT)。

生年月日・没年月日の表示は、既存の表示設定(西暦/和暦・粒度)に追従しなければならない(MUST)。

#### Scenario: 人物属性が列として表示される
- **GIVEN** 姓・名・ふりがな・性別・生没年月日・生没地・メモを持つ人物が登録されている
- **WHEN** 表形式ビューを表示する
- **THEN** その人物の行に各属性が対応する列の値として表示される

#### Scenario: 日付列が表示設定に追従する
- **GIVEN** 生年月日が記録された人物が表に表示されている
- **WHEN** 表示設定の表示形式を和暦へ変更する
- **THEN** 表の生年月日・没年月日の列が和暦表示に切り替わる

#### Scenario: 配偶者列は読み取り専用
- **GIVEN** 配偶者を持つ人物が表に表示されている
- **WHEN** 編集モードで配偶者列のセルを編集しようとする
- **THEN** 編集は開始されず、配偶者の氏名が表示されたまま変化しない

### Requirement: 並べ替えと絞り込み

表形式ビューは、列見出しの操作による並べ替え(少なくとも氏名・生年月日)と、氏名・ふりがなの部分一致による絞り込みを提供しなければならない(MUST)。並べ替え・絞り込みは表示のみに作用し、家系図データを変更してはならない(MUST NOT)。

#### Scenario: ふりがなで絞り込む
- **GIVEN** 「やまだ」「さとう」のふりがなを持つ人物が混在して登録されている
- **WHEN** 絞り込みに「やまだ」を入力する
- **THEN** ふりがな(または氏名)が一致する人物の行のみが表示される

#### Scenario: 生年月日で並べ替える
- **GIVEN** 生年月日の異なる複数の人物が登録されている
- **WHEN** 生年月日の列見出しで並べ替えを実行する
- **THEN** 行が生年月日順に並び、生年月日が未入力の人物は末尾に置かれる

### Requirement: 選択の共有

表の行の選択は、図・パネルと同一の選択状態を共有しなければならない(MUST)。表で人物を選択して図へ切り替えた場合、その人物が選択された状態でなければならない(MUST)。人物が選択された状態で表を開いた場合、その人物の行が視認できる位置に表示されなければならない(SHALL)。

#### Scenario: 表で選んだ人物が図でも選択されている
- **GIVEN** 表形式ビューで特定の人物の行を選択した
- **WHEN** 図へ切り替える
- **THEN** その人物のカードが選択状態で表示される

### Requirement: 閲覧モードと編集モードの切り替え

表形式ビューは「閲覧モード」(既定)と「編集モード」を明示的な操作で切り替えられなければならない(MUST)。閲覧モードではセルの編集を開始できてはならない(MUST NOT)。

#### Scenario: 閲覧モードでは編集できない
- **GIVEN** 表形式ビューが閲覧モードである
- **WHEN** セルをクリックまたはキー入力する
- **THEN** セルの編集は開始されない(行の選択のみが行われる)

#### Scenario: 編集モードへの切り替え
- **GIVEN** 表形式ビューが閲覧モードである
- **WHEN** 編集モードへ切り替える
- **THEN** セルの編集・コピー&ペーストの操作が有効になる

### Requirement: セル編集

編集モードでは、属性セルの値を編集して確定すると、その人物の属性が即座に更新されなければならない(MUST)。1セルの確定は1回の undo で戻せなければならない(MUST)。値が変わらない確定は undo 履歴に積まれてはならない(MUST NOT)。

キーボード操作は表計算の慣行に従わなければならない(MUST): Enter=確定して下のセルへ、Tab=確定して右のセルへ、Esc=編集を取り消す。IME(日本語入力)の変換確定の Enter をセル移動として扱ってはならない(MUST)。

#### Scenario: 氏名セルの編集が反映される
- **GIVEN** 編集モードで人物の「姓」セルを編集している
- **WHEN** 新しい値を入力して Enter で確定する
- **THEN** その人物の姓が更新され、フォーカスは下のセルへ移動し、undo を1回実行すると元の姓に戻る

#### Scenario: IME変換中のEnterで移動しない
- **GIVEN** 氏名セルで日本語入力の変換候補を選んでいる(未確定文字列がある)
- **WHEN** 変換確定の Enter を押す
- **THEN** 文字の変換だけが確定し、セルの確定・移動は起こらない

### Requirement: 日付セル・性別セルの解釈

生年月日・没年月日セルの入力は、既存の日付解釈(西暦の年月日表記・ハイフン区切り・8桁数字・和暦・「頃/以前/以後」等の修飾)に従って解釈されなければならない(MUST)。解釈された日付は入力の原文(original)も既存の入力欄と同じ規則で保持しなければならない(MUST)。解釈できない値は人物データを変更せず、該当セルにエラーとして明示されなければならない(MUST)。

性別セルは「男」「女」「不明」およびそれらの一般的な別表記(M/F/U、male/female/unknown)を受理しなければならない(SHALL)。

#### Scenario: 和暦の日付入力
- **GIVEN** 編集モードで人物の生年月日セルを編集している
- **WHEN** 「昭和39年10月10日」を入力して確定する
- **THEN** 生年月日が1964年10月10日として記録され、原文「昭和39年10月10日」も保持される

#### Scenario: 解釈できない日付
- **GIVEN** 編集モードで人物の生年月日セルを編集している
- **WHEN** 「昭和99年13月40日」のような解釈できない値を確定する
- **THEN** 人物の生年月日は変更されず、該当セルにエラーが表示される

### Requirement: 矩形選択とコピー

編集モードでは、セルの矩形範囲を選択できなければならない(MUST)(Shift+クリックまたは Shift+矢印キー)。Ctrl+C(または同等操作)で、選択範囲のセルの表示文字列をタブ区切り(TSV)・行は改行区切りとしてクリップボードへコピーしなければならない(MUST)。セル値にタブ・改行・引用符を含む場合は、表計算ソフトと相互運用できる引用符形式で書き出さなければならない(MUST)。

#### Scenario: 矩形範囲のコピー
- **GIVEN** 編集モードで2行×2列のセル範囲を選択している
- **WHEN** Ctrl+C を押す
- **THEN** クリップボードに2行のタブ区切りテキストが書き込まれ、表計算ソフトへ2×2の範囲として貼り付けられる

#### Scenario: 改行を含むメモのコピー
- **GIVEN** 複数行のメモを持つ人物のメモセルを選択している
- **WHEN** Ctrl+C を押す
- **THEN** メモは引用符で囲まれた1セルとして書き出され、表計算ソフトで1セルに収まる

### Requirement: ペースト

編集モードでは、Ctrl+V(または同等操作)でクリップボードのタブ区切りテキストを、選択セルを起点として行×列に展開して適用しなければならない(MUST)。表計算ソフト(Excel・Google スプレッドシート)からコピーした範囲を受け付けなければならない(MUST)。

1回のペーストによる変更全体(複数セルの更新・行の追加を含む)は、1回の undo で丸ごと戻せなければならない(MUST)。

ペースト範囲に解釈できない値が含まれる場合、解釈できたセルは適用し、できなかったセルは適用せずに、どのセルが取り込めなかったか(行×列と理由)を利用者へ明示しなければならない(MUST)。

絞り込みが適用されている間のペーストは、表示されている行にのみ適用され、非表示の行を跨いで上書きしてはならない(MUST NOT)。

#### Scenario: 表計算ソフトからの貼り付け
- **GIVEN** Excel で氏名・生年月日の2行×2列をコピーしてある
- **WHEN** 編集モードで起点セルを選んで Ctrl+V を押す
- **THEN** 2人の人物の該当属性が一括で更新される

#### Scenario: 不正な値が混在する貼り付け
- **GIVEN** 貼り付け範囲に解釈できない日付が1セル含まれている
- **WHEN** Ctrl+V を押す
- **THEN** 解釈できたセルは適用され、できなかったセルは行×列と理由つきで明示され、該当人物のその属性は変更されない

#### Scenario: 貼り付け全体を1回のundoで戻す
- **GIVEN** 複数行×複数列の貼り付けを実行した
- **WHEN** undo を1回実行する
- **THEN** 貼り付けによる変更(追加された人物を含む)がすべて元に戻る

### Requirement: 行追加による人物の追加

編集モードでは、表の末尾で新しい行に値を入力することで人物を追加できなければならない(MUST)。追加された人物は「関係を決めずに登録した人物」と同じ扱いでなければならない(MUST)(関係リンクは図・パネル側で後から結ぶ)。

すべてのセルが空のままの行からは人物を作成してはならない(MUST NOT)。

ペースト範囲が既存の行数を超える場合、超過分の行は新規人物として同じペースト操作の中で追加されなければならない(MUST)。

#### Scenario: 新しい行への入力で人物が追加される
- **GIVEN** 編集モードで表の末尾の新規入力行にフォーカスしている
- **WHEN** 姓のセルに値を入力して確定する
- **THEN** その姓を持つ人物が1人追加され、図・「図に現れていない人物」の一覧など既存のふるまいに従って現れる

#### Scenario: 行数を超える貼り付けで人物が追加される
- **GIVEN** 表示中の行が残り1行の位置を起点に、3行分のデータをコピーしてある
- **WHEN** Ctrl+V を押す
- **THEN** 既存の1行が更新され、超過した2行分は新規人物として追加される

### Requirement: 既存の編集経路との等価性

表での編集(セル編集・ペースト・行追加)は、図・パネルでの編集と同じ保存・履歴・保護のふるまいに従わなければならない(MUST): 自動保存の対象になり、undo/redo の履歴を共有し、保存が停止する状態(読み取り専用・別タブ編集の検出等)では表の編集も同様に停止しなければならない(MUST)。

#### Scenario: 表の編集が自動保存される
- **GIVEN** 編集モードでセルを編集して確定した
- **WHEN** 自動保存が完了する
- **THEN** ヘッダーの保存状態が既存の編集と同様に「保存済み」となり、リロード後も変更が保持されている

#### Scenario: 保存できない状態では編集も停止する
- **GIVEN** 別タブでの編集が検出され、このタブの保存が停止している
- **WHEN** 表形式ビューを表示する
- **THEN** 編集モードは利用できず、既存の案内(再読み込みの導線)が表示される

### Requirement: 表が提供しない操作

表形式ビューは、人物の削除、および関係(親子・配偶者・続柄・婚姻/離婚)の編集手段を提供してはならない(MUST NOT)。これらは影響範囲の予告を伴う既存の導線(図+パネル)に限定する。

#### Scenario: 表から削除・関係編集はできない
- **GIVEN** 表形式ビューを表示している
- **WHEN** 行・セルに対する操作(クリック・キーボード・コンテキスト操作)を行う
- **THEN** 人物の削除・関係の変更に至る操作は存在しない
