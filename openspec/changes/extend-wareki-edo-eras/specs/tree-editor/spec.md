## MODIFIED Requirements

### Requirement: 和暦対応の日付入力
日付入力フィールドは和暦・西暦のどちらの形式でも入力を受け付け、入力と同時にもう一方の表記を表示しなければならない(SHALL)。西暦の入力は、年のみ・「年月日」漢字表記・ハイフン区切り(例: `1964-10-10`)・スラッシュ区切り(例: `1964/10/10`)・区切りなし8桁数字(例: `19641010`)のいずれの表記でも受け付けなければならない(SHALL)。「頃」「以前」「以後」等の修飾子も入力できなければならない(MUST)。和暦の元号は明治以降に限らず、大化(645年)から令和までの元号(南北朝期は北朝系列のみ)を受け付けなければならない(SHALL)。明治6年(1873年)のグレゴリオ暦採用より前の日付については、旧暦(太陰太陽暦)への正確な換算は行わず、日は1〜30日の範囲であれば妥当な日付として受理しなければならない(SHALL)。

#### Scenario: 和暦入力時の西暦即時表示
- **WHEN** 出生日欄に「昭和39年10月10日」と入力する
- **THEN** 入力欄の近傍に「1964年10月10日」が即時表示され、確定するとFuzzyDateとして保存される

#### Scenario: 西暦入力時の和暦即時表示
- **WHEN** 出生日欄に「1964-10-10」と入力する
- **THEN** 「昭和39年10月10日」が即時表示される

#### Scenario: 区切りなし8桁数字での入力
- **WHEN** 出生日欄に「19641010」と入力する
- **THEN** 「1964年10月10日」相当の日付として解釈され、「昭和39年10月10日」が即時表示される

#### Scenario: 不正な日付の入力
- **WHEN** 「昭和65年1月1日」と入力する
- **THEN** その場でエラー理由(昭和は64年まで)が表示され、確定できない

#### Scenario: 江戸後期の元号での入力
- **WHEN** 出生日欄に「文久2年5月10日」と入力する
- **THEN** 「元号「文久」には対応していません」というエラーにはならず、対応する西暦日付が即時表示される

#### Scenario: 明治6年より前の日付は暦法非依存の緩い妥当性で受理される
- **WHEN** 「安政3年2月30日」と入力する
- **THEN** グレゴリオ暦の2月には30日が存在しないが、明治6年より前の日付として受理され、対応する西暦が即時表示される

#### Scenario: 明治6年より前でも範囲外の日は拒否される
- **WHEN** 「安政3年2月31日」と入力する
- **THEN** 31日は許容範囲(1〜30日)外のため、その場でエラーが表示され確定できない

#### Scenario: 南朝の元号は非対応
- **WHEN** 「天授2年」のような南朝(南北朝期)の元号を入力する
- **THEN** 「元号「天授」には対応していません」というエラーが表示され、確定できない
